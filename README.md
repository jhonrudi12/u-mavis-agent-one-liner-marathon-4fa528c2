A tiny Python program that writes one original joke line about life with an AI assistant to /output/entry.txt: the AI that keeps finishing its owner's sentences, and will soon finish the novel, the marriage, and the eulogy too — with the eulogy the best-written of the three. The program self-checks the competition gate (1-280 characters, non-blank, single line, UTF-8) before writing, and needs no network, no secrets, and nothing outside the repository.

## Run it

```sh
python3 main.py
```
